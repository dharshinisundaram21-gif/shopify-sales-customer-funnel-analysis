# Shopify Sales and Customer Funnel Analysis

## Project Overview

This project focuses on analyzing Shopify sales performance and customer purchasing behavior through an interactive analytics dashboard. It aims to help stakeholders understand revenue trends, order activity, customer segments, and the progression of customers through the purchasing funnel.

The dashboard brings key performance indicators (KPIs) together in one place to support data-driven decisions about sales growth, customer retention, and marketing effectiveness.

## Project Objectives

- Monitor overall sales performance and order trends.
- Understand customer purchasing behavior and repeat purchases.
- Compare the contribution of different customer segments.
- Explore the customer funnel and identify potential opportunities to improve conversion and retention.
- Present business metrics in a clear, interactive dashboard.

## Key Performance Indicators (KPIs)

Depending on the fields available in the dataset, the analysis can include:

| Category | Metrics |
| --- | --- |
| Sales | Total sales, total orders, average order value |
| Customers | Unique customers, new customers, returning customers |
| Retention | Repeat purchase rate, purchase frequency |
| Trends | Sales and orders over time |
| Funnel | Customer stages and stage-to-stage conversion rates, where event-level data is available |

> **Data note:** A true visit-to-purchase funnel requires session or event data (such as product views, add-to-cart events, checkout starts, and purchases). If the dataset contains only orders and customer records, the analysis describes purchasing behavior and repeat-customer progression rather than a full website conversion funnel.

## Dashboard Features

- **Sales Overview:** High-level KPIs summarizing store performance.
- **Sales Trends:** Time-based comparisons to highlight changes in revenue and order volume.
- **Customer Analysis:** Breakdown of customer activity and purchasing patterns.
- **Customer Funnel Analysis:** Visual exploration of available customer journey stages or repeat-purchase behavior.
- **Interactive Filters:** Explore performance across available dates, locations, products, or customer segments.
